# Демо-данные (синтетика)

Загружаются в БД командой `python -m app.seed` только при `SEED_DEMO_DATA=true` (в Docker Compose включено по умолчанию). Повторный запуск не создаёт дублей.

- `products.json` — три продукта из `docs/plan.md`, раздел 7. Единственный источник каталога для backend.
- `news.json` — 28 синтетических новостей ленты с тегами (ОКВЭД, сегмент, продукт, статус), см. `docs/ml-ranking.md`.
- `demo-files/declaration.pdf` — синтетическая декларация ИП Мельниковой за 2025 год с пометкой «образец». Её клиент загружает по запросу банка в сценарии демо (план, раздел 15). Шрифт — Inter (OFL).
- `companies.json`, `users.json` — демо-учётки из раздела 15 плана. Пароль у всех — `Demo2026!`, он публичный и нужен только для проверки стенда. В БД хранится bcrypt-хэш.

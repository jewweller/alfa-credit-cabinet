# Фикстуры моков ЕГРЮЛ / ЕГРИП / ФНС / БКИ (черновик)

**Статус: черновик, не утверждён аналитиком.** Вопросы — `docs/analyst-questions.md`, раздел 6.

Синтетические ответы внешних источников по тестовым ИНН (`docs/plan.md`, раздел 8). Пока заполнены четыре демо-клиента, нужные для четырёх исходов: Пекарня (APPROVED), Ковалёв (COUNTER_OFFER), СтройРесурс (REJECTED), Мельникова (INFO_REQUESTED).

Формат записи:

- `response` — тело ответа ровно по контракту мока из раздела 8 плана;
- `sources` — происхождение каждого значения: `P7` / `P8` — разделы плана, `FE` — реестр в моках фронта, `DERIVED` — однозначно следует из баллов плана, `TECH` — технический идентификатор, `TBD` — значения нет (поле `null`, движком не используется).

Сейчас файлы читает backend напрямую (`app/integrations/fixtures.py`); позже их же будет отдавать HTTP-сервис `mocks` (порт 8081). Если ИНН в файле нет: реестр отвечает «компания не найдена» (как 404), ФНС и БКИ — «источник недоступен».

Это не данные ML: ML исключил эти ИНН из генерации (`ml/synth/config.yaml`, `reserved_inns`). Каталог продуктов здесь не повторяется — он в `seed/products.json`.

Формат записи:

- `response` — тело ответа ровно по контракту мока из раздела 8 плана;
- `sources` — происхождение каждого значения: `P7` / `P8` — разделы плана, `FE` — реестр в моках фронта, `DERIVED` — однозначно следует из баллов плана, `TECH` — технический идентификатор, `TBD` — значения нет (поле `null`, движком не используется).

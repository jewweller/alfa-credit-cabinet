# Сценарии проверки

Пошаговая проверка прототипа в браузере и через API. Все данные синтетические. Пароль у всех учёток — `Demo2026!`; на экране входа учётки перечислены, нажатие подставляет логин.

Стенд: `docker compose up --build`, затем http://localhost:8080. Ожидаемые результаты ниже проверены на стенде 25.10.2026.

## 0. Подготовка

1. Войти как `admin@demo.local` — откроется «Администрирование».
2. В панели «Сброс демо-данных» нажать «Сбросить данные» → «Да, сбросить».
3. Ожидается: «Готово: удалено заявок — N»; в журнале действий появилась строка «Сброс демо».

После сброса заявок нет ни у кого: учётки, компании, продукты и журнал остаются.

## 5. Ручное рассмотрение без документов — Мираж и Сбой-Тест

- `mirage@demo.local`: 2 000 000 ₽ на 12 мес, выручка 12 000 000 ₽, платежи 0 → «Заявку смотрит специалист» (грейд D, правило R7). Если указать выручку 20 000 000 ₽ — расхождение с ФНС 66,7 %, и банк запросит документы (R4).
- `sboy@demo.local`: те же данные → специалист (правило R3: недоступен источник БКИ). В карточке у источника БКИ — «не ответил».

## 6. Лента меняется от клиента к клиенту

Открыть «Вся лента» у Пекарни, Ковалёва и Мельниковой и сравнить новости.

- Отраслевые заметки — только своей отрасли: у Пекарни про муку и выпечку, у Ковалёва про розничную торговлю. Чужих отраслей нет.
- Подсказки к шагу — по статусу своих заявок: «Что проверить перед подписанием» при одобрении, «Деньги выданы: как не пропустить первый платёж» после выдачи.
- В каждой новости — «Почему вы это видите»: ОКВЭД, сегмент, продукт или этап заявки.
- В панели «Как подбираются новости» — веса правил и версия подбора; порядок задаёт модель `feed-logreg-1.0.0`, при её сбое — правила.

## 7. Администратор

Учётка `admin@demo.local`.

- «Журнал действий»: входы, неудачные попытки входа, действия клиентов, смены статусов, загрузка и просмотр файлов, решения специалистов, сброс. Фильтры по группам, «Показать ещё».
- «Очередь заявок» и карточка заявки доступны только для чтения: кнопок «Взять в работу» и решения нет, API отвечает 403.

## 8. Через API

Коллекция `docs/api/collection.postman.json` повторяет сценарии 1–4 и 7 и проверяет ответы (42 запроса, 62 проверки). Из корня репозитория:

```bash
npx newman run docs/api/collection.postman.json
```

Последняя папка коллекции сбрасывает демо-данные. Swagger — http://127.0.0.1:8000/api/docs.

# Результаты проверенного эксперимента

[Полный отчёт](full-size.md) относится к трём независимым seed: 42, 43, 44,
по 20 000 компаний каждый. Генерация дала 60 023 / 60 166 / 60 114 запросов
и 959 135 / 960 763 / 956 504 кандидата. Доля позитивных непустых запросов —
61,97% / 61,49% / 61,72%, внутри диапазона 55–70% из ТЗ.

| Метрика NDCG@3, среднее ± стандартное отклонение | Модель | Бейзлайн B |
|---|---:|---:|
| Показанные кандидаты, запросы с позитивами | 0,6983 ± 0,0144 | 0,6425 ± 0,0084 |
| Показанные кандидаты, все запросы | 0,4219 ± 0,0109 | 0,3882 ± 0,0087 |
| Все кандидаты, скрытая ожидаемая полезность | 0,8569 ± 0,0008 | 0,8017 ± 0,0051 |

Прирост на позитивных запросах — около 0,056 абсолютного NDCG@3. Контрольная
модель с перемешанными метками даёт 0,5580 против 0,5568 случайного порядка.
Модель только на полях кандидата имеет oracle NDCG@3 0,7696 против 0,8569 полной
модели и 1 идеального порядка. Результат показывает сигнал в этом симуляторе;
он не доказывает пригодность модели для реальных клиентов.

`full-size.json` содержит параметры, NDCG@3/@5, MAP@3, каждую контрольную модель,
число оцениваемых групп, важность признаков и метрики по регионам/сегментам.
Oracle-группы, в которых полезность всех вариантов равна нулю, не имеют
осмысленного идеального порядка: их число отражено в `zero_gain_queries`.

`full-run-metadata.json` содержит манифесты и диагностики трёх наборов. Два
независимых полных запуска seed 42 дали **байт-в-байт одинаковые 16 файлов**.
Бинарные полные наборы в Git не включены; их можно воспроизвести командой ниже.
Небольшой полный пример находится в `ml/examples/`, модель seed 42 — в `ml/models/`.

```sh
uv sync --project ml --frozen
uv run --project ml python -m ml.synth.experiment \
  --seeds 42 43 44 --out ml/runs/reproduce-full
```

Пилот на 2 000 компаний на seed сохранён в `pilot-2000.md` / `pilot-2000.json`.
Он служит отдельной проверкой масштаба и не смешивается с полными метриками.
Обе серии использовали одну окончательную конфигурацию распределений и
параметры обучения по умолчанию, без подбора параметров по тесту.

Состояние проверок при сдаче: 62 pytest-теста проходят, Ruff проходит,
TypeScript/Python аннуитет совпадает на 203 случаях. Коридоры грейдов, полной
воронки и минимальный прирост для внедрения остаются открытыми вопросами ТЗ;
`deployment_ready` остаётся `false`.
